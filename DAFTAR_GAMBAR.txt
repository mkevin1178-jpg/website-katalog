TIPS UMUM
---------
- Foto produk / galeri   : JPG atau WebP, rasio persegi (1:1), min. 800x800 px
- Foto hero / tentang    : JPG biasa, rasio 3:2 atau 4:3 (ditampilkan dalam
                           bingkai rounded-3xl, TIDAK perlu transparan)
- Ornamen / cut-out CTA  : PNG atau WebP TRANSPARAN (background dihapus)
- Ukuran file ideal      : 100-500 KB per foto (kompres di squoosh.app /
                           tinypng.com). JANGAN upload file mentah HP (>2 MB).
- Nama file              : huruf kecil, pakai tanda minus, tanpa spasi
                            (contoh: kapal-selam-jumbo.jpg)
